# Digital Learning Management System (LMS-Portal)

## About the Project

The Digital Learning Management System (LMS) is a Java Full Stack web application developed to simplify online learning and course management. It allows students to access courses, instructors to manage course content, and administrators to manage the overall system.

## Features
- Student Registration and Login
- Course Management
- Student Enrollment
- View Available Courses
- Admin Dashboard
- Responsive User Interface
- Online Quiz Module

## Technologies Used
- Java
- Spring Boot
- HTML
- CSS
- JavaScript
- MySQL
- Maven

## How to Run

1. Clone the repository.
2. Open the project in Eclipse or VS Code.
3. Configure the MySQL database.
4. Run the project using:

```bash
mvn spring-boot:run
```

5. Open your browser and visit:

```
http://localhost:8080
```
